# age identities for YubiKey-backed sops.

# This is the DEFAULT path sops looks for (~/.config/sops/age/keys.txt), so no
# SOPS_AGE_KEY_FILE export is needed.
#
# These are NOT secret. Each line is a stub encoding a serial + PIV slot; the
# actual private key is non-exportable and never leaves the YubiKey. Mode 600 is
# defence in depth, not a requirement.
#
# Both keys are interchangeable — either decrypts anything encrypted to both.
# Requires `age-plugin-yubikey` on PATH and a running pcscd.
#
# Decryption takes a touch and no PIN. Regenerating a key (new PIN/touch policy,
# lost key) changes its recipient, so these stubs and ~/.sops.yaml must be
# updated together.
#
# See prog/infra/secrets.md for the full setup, rationale and recovery notes.
